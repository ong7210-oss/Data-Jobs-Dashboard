## Introduction

Navigating the data job market can feel confusing because information is everywhere. This dashboard (V2.0) is made for **Job Seekers, people changing careers, and people switching jobs to make things simpler.** It uses real 2024 data science job posting data, including job titles, salaries, and locations. The dashboard is built as a simple one-page view so users can quickly understand job trends and salary insights.

## Skills Showcased

* **Dashboard Design:** Creating a clean and easy-to-understand report layout.
* **Power Query ETL:** Cleaning, organizing, and transforming the data.
* **Data Modeling:** Building a structured data model using relationships (based on Star Schema).
* **DAX Fundamentals:** Creating basic calculations to get useful insights.
* **📊 Visualizations Utilized:**
    * **Core Charts:** Column, Bar, Line, and Area charts to compare data and show trends.
    * **Map Charts:** Showing data based on location.
    * **Cards:** Displaying important key numbers clearly.
    * **Tables:** Showing detailed data in table form.
    * **Chart Variety:** Using different chart types to make the story clearer.
* **🖱️ Interactive Features:**
    * **Slicers:** Letting users filter data easily.
    * **Buttons & Bookmarks:** Helping users move around the dashboard and control views (including Drill-Through).

## Dashboard Overview

This second version puts everything into one simple page, made to give job seekers the most important insights quickly and clearly.

![Dashboard Page 1](/Images/Picture%203.png)  

This page works like your main control panel for the data job market. It shows key numbers (KPIs) such as **Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary.** You can also easily check **Skill Popularity** (by percentage or count) and **compare salaries** across different Job Titles. Everything is designed to give a fast and clear overview.

## Conclusion

This updated dashboard (Version 2.0) shows how Power BI can turn a large amount of job data into a simple and useful tool for career analysis. It helps **job seekers, career changers, and job switchers** explore important insights easily on one page, so they can make better decisions for their next career step.
