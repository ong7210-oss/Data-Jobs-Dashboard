## Introduction

This dashboard is made for job seekers and people who want to change jobs. The problem is that information about data jobs is everywhere and hard to understand. Using **real data from 2024 job postings** (job titles, salaries, and locations), this dashboard puts everything in one place so users can easily see job trends and salary information.

## Skills Showcased

- **Data Transformation (ETL) with Power Query:** Cleaned and prepared the raw data by removing missing values, fixing data types, and adding new columns.
-   **Implicit Measures:** Created measures to get important insights such as `median yearly salary` and `job count`.
-   **Core Charts:** Used column, bar, line, and area charts to compare job numbers and show trends over time.
-   **Geospatial Analysis:** Used map charts to show where jobs are located around the world.
-   **KPI Indicators & Tables:** Used cards to show key numbers and tables to display detailed and sortable data.
-   **Dashboard Design:** Designed the dashboard to be simple, clear, and easy to use, with suitable chart types to explain the data.
-   **Interactive Reporting:**
    -   **Slicers:** Filter data by job title.
    -   **Buttons & Bookmarks:** Easy navigation between pages.
    -   **Drill-Through:** Click to see more detailed information from summary views.

## Dashboard Overview

### Page 1: High-Level Market View

![Dashboard Page 1](/Images/Picture%201.png)  

This dashboard is like your main control panel for the data job market. It shows important information such as total number of jobs, median salary, and top job titles, so you can quickly understand what is happening in the job market.

### Page 2: Job Title Drill Through

![Dashboard Page 2](/Images/Picture%202.png)   

This is the detailed page. From the main dashboard, you can click and go to this page to see more information about one job title. It shows salary range, work-from-home data, top hiring platforms, and job locations around the world.

## Conclusion

This dashboard shows how Power BI can turn raw job data into a useful tool for career analysis. Users can filter, explore, and view details to help them make better career decisions.
